# Реверс-прокси на Nginx

[English](README.md)

Nginx на VPS передаёт запросы к вашему домену серверу с сайтом.
Certbot выпускает и продлевает сертификат HTTPS.

## Установка и первый сайт

Нужен чистый VPS с Debian 12/13 или Ubuntu 22.04/24.04, systemd и доступом
через root или `sudo`. Установщик остановится, если найдёт пользовательские конфиги Nginx.

- Направьте A-запись домена на VPS. Оставьте AAAA только если VPS работает
  по указанному IPv6-адресу. Если DNS-провайдер предлагает проксирование,
  выберите режим «только DNS».
- Откройте входящие TCP-порты **80** и **443**. Порт 80 нужен и для продления
  сертификатов.
- Подготовьте адрес сервера с сайтом. Он должен быть доступен с VPS и отдавать
  сайт при запросе с публичным именем домена. Укажите HTTP- или HTTPS-адрес
  без пути.

Выполните на VPS по SSH. Если вошли как root, уберите `sudo`.

```sh
sudo apt update && sudo apt install -y git
git clone https://github.com/NikKurkov/nginx-reverse-proxy.git
cd nginx-reverse-proxy
sudo ./install.sh
sudo nginx-reverse-proxy add
```

Введите домен, адрес сервера с сайтом и email для Let’s Encrypt, затем
подтвердите запуск. Скрипт проверит DNS, запросит сертификат и включит
перенаправление на HTTPS. После сообщения `Ready` откройте домен в браузере.

## Управление сайтами

```sh
sudo nginx-reverse-proxy add example.com \
  --origin http://192.0.2.20:8080 --email admin@example.com --yes
sudo nginx-reverse-proxy list
sudo nginx-reverse-proxy remove example.com
```

- Ключ `--www` добавляет имя с `www`. Сначала направьте его DNS на VPS.
- Команда `add --file domains.txt` с теми же параметрами читает список
  доменов, по одному на строку. При ошибке скрипт откатывает конфиг
  текущего сайта и останавливается.
- Чтобы повторно использовать адрес сервера и email, заполните `origin=`
  и `email=` в `/etc/nginx-reverse-proxy/defaults`. Если подключаетесь к
  серверу по HTTPS через IP, передайте имя из его сертификата через `--tls-name`.
- Команда `remove` сохраняет конфиг и сертификат. Команда `add` не перезаписывает
  существующий конфиг. У отключённого сайта сертификат может истечь.

Если сайт не добавляется, проверьте DNS и порт 80, затем посмотрите вывод
Certbot. При ответе 502 проверьте доступность сервера с VPS и откройте
`/var/log/nginx/error.log`. Все параметры есть в `nginx-reverse-proxy --help`.
